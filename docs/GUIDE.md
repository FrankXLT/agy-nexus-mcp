# Welcome to AGY-Nexus MCP

If you are seeing **AGY-Nexus MCP** for the first time, think of it as a quiet control room that connects your mobile or browser Gemini chat directly to your local coding workstation—without opening your workspace to the public internet or burning top-tier model credits on routine tasks.

This guide explains what AGY-Nexus MCP does in everyday language and translates the project's builder shorthand into clear concepts. When you are ready for module layouts, protocol internals, and security gates, jump into [`docs/HOW_IT_IS_BUILT.md`](HOW_IT_IS_BUILT.md).

---

## Three Everyday Payoffs

1. **Steer your local Antigravity coding workstation from Gemini on a phone or web browser (`ag-bridge-mcp`)**  
   Read files, inspect git diffs, review screenshots, and send a structured handoff back to your desktop IDE while away from your desk—protected behind a secret URL and a spoken or typed passphrase.

2. **See real Gemini and Claude Quota & Resets Percentage Left plus API equivalent value alongside `Plus` / `Pro` / `Ultra 5x` / `Ultra 20x` subscriptions in one calm dashboard**  
   Instead of guessing how much headroom remains in your subscription pools, open `/web` (or ask Gemini directly) to view live `100%` down to `0%` bars, reset countdowns, and what the same token volume would cost at public API rates.

3. **Route everyday scouting, doc updates, and routine code edits to faster lower-cost helper models with clean Model Routing Checks**  
   Keep directory scans, test runs, documentation edits, and straightforward wiring on nimble helper agents while reserving heavier reasoning models for system architecture, concurrency, and independent security review.

## Builder Shorthand, Translated

### 1. Two-Doorway Setup

AGY-Nexus MCP separates **remote access** from **local IDE indexing** using two distinct doorways so each environment gets only the access it needs:

- **External Locked Doorway (`ag-bridge-mcp`)**:  
  Built for Google Gemini (Mobile and Web) and remote MCP clients. Over HTTP, it listens on `BIND_HOST=0.0.0.0` port `8765` behind a random 12-character subdomain and 48-character path (`https://ag-{SUBDOMAIN_HASH}.<your-domain>/{PATH_SECRET}/mcp`). Every private read or handoff tool stays locked until you verify your passphrase.
  - **Container `--stdio` option**: For local MCP clients (VS Code, Copilot CLI, Claude Code, or MCP Inspector), you can launch the public OCI image (`ghcr.io/frankxlt/agy-nexus-mcp:4.2.0 --stdio`) over standard input/output with zero `stdout` banners and no `PATH_SECRET` needed. Without `PASS_HASH`, safe catalog tools such as `list_models_and_agents` work right away while private workspace tools stay fail-closed.
- **Local Workstation IDE Doorway (`agy-praxis-mcp`)**:  
  Built for your Antigravity IDE and local subagents running on the same machine. It connects locally at `/praxis/{PRAXIS_MCP_TOKEN}/mcp` (with backward-compatible `/polyglot/{POLYGLOT_MCP_TOKEN}/mcp` support) or via `--stdio` (`python3 -m agy_nexus.tools_praxis --stdio`). `PRAXIS_MCP_TOKEN` is derived deterministically from `PATH_SECRET` (`HMAC-SHA256(PATH_SECRET, "agy-praxis-mcp-v1")[:48]`) and strictly rejects reverse-proxy headers, browser `Origin` headers, public `Host` names, and non-private client IPs.
- **Loopback Host Companion (`agy-host-bridge.service`)**:  
  Runs strictly on `127.0.0.1:8098` (authenticated by `HOST_BRIDGE_TOKEN` in `X-Bridge-Token`) whenever the MCP server needs to wake an Antigravity chat session, register a new project, or inspect host worktree state.

### 2. Thirty-Minute Passphrase Lock

Even if someone somehow guessed your random URL, the external doorway stays shut behind an inactivity deadbolt:

- **Configurable lock timer (`TTL_SECONDS`)**: Set `TTL_SECONDS=1800` in `/home/dev/.config/ag-bridge-mcp/secrets.env` (`0600` permissions) for a **30-minute inactivity lock**. The default generated by `scripts/init_secrets.py` is `7200` seconds (2 hours), and the enforced minimum floor is `300` seconds (5 minutes).
- **Spoken or typed SHA-256 verification**: Your passphrase is never stored in plain text—only its `PASS_HASH` (64-character SHA-256 digest). Input normalization strips punctuation and ignores letter case, so speaking your phrase into Gemini on a phone unlocks the bridge just as reliably as typing it.
- **Explicit lock**: You can also lock the bridge on demand at any time with `lock_bridge`.

### 3. Quota & Resets Percentage Left

The `/web` dashboard (and the `get_session_tree` / `list_models_and_agents` MCP tools) turns raw session logs into clear remaining-headroom gauges:

- **Live `100%` down to `0%` bars**: Each model pool displays how much capacity remains right now alongside clear status labels:
  - `OK` — plenty of headroom left in the current window
  - `LOW LEFT` — getting low; shift routine edits to lighter helper tiers
  - `NEAR LIMIT` — nearly exhausted; hold remaining capacity for critical fixes or wait for the reset countdown
- **Reset countdowns**: Shows the exact `resets in ...` window next to each pool so you know when fresh capacity arrives.
- **Subscription & API equivalent context**: Compares your actual usage and API-rate equivalent value side by side against `Plus`, `Pro`, `Ultra 5x`, and `Ultra 20x` plan tiers, backed by the two-file Price Book (`src/agy_nexus/data/model_catalog.json` and `src/agy_nexus/data/cost_ledger.json`) with optional 1-click upstream updates in `/web`.

### 4. Model Routing Check

Running every small edit through a flagship model drains scarce pool quota fast. A **Model Routing Check** keeps each task matched to the right tier:

- **Live pool check (`quota-router.sh`)**: Run `quota-router.sh status` or `quota-router.sh route <role> json` to inspect active pool cooldowns, main-chat affinity, and `% left` before dispatching work.
- **Helper tiers for everyday work**:
  - `flash-scout` — fast multi-file reconnaissance, symbol mapping, and log scanning
  - `flash-surgeon` — mechanical edits, tests, docs, version bumps, and cohesive file splits
  - `hydrogen-surgeon` — everyday multi-file feature and API wiring
  - `neon-surgeon` — CSS layout geometry, client state, and SVG/chart views
- **Heavier tiers reserved for high-stakes work**:
  - `argon` (`argon-architect`, `argon-surgeon`, `argon-sentinel`) and `carbon` (`carbon-sentinel`) handle 1M-context blueprints, concurrency, state machines, and orthogonal Tab 1 dual-review at zero Partner pool cost.
  - `claude-specialist` and `claude-sentinel` (Claude 5.5) stay reserved in Tab 2 for Strike-2 escalations and cross-family security audits.
- **Intended vs. actual receipts**: Telemetry tracks both each role's intended `targetModel` and the actual model executed—flagging cases like `Intended: Sonnet 5.5 · Ran: 84% Carbon 4 (inherited)` and alerting you with a 1-click GitHub issue link if a brand-new `MODEL_PLACEHOLDER_M*` code appears unmapped.

## First-Time Quick Checks

1. **Generate secrets outside the repo** (writes `/home/dev/.config/ag-bridge-mcp/secrets.env` with `0600` permissions):
   ```bash
   python3 scripts/init_secrets.py --domain <your-domain>
   ```
   To tighten the inactivity lock to 30 minutes, set `TTL_SECONDS=1800` inside `~/.config/ag-bridge-mcp/secrets.env` (never lower than `300`).
2. **Verify your local setup** before connecting Gemini:
   ```bash
   python3 ag_bridge.py --self-test
   python3 -m agy_nexus.tools_praxis --self-test
   ```
3. **Preview the dashboard without touching live data**: Open `/web?demo=1` locally or browse `./demo/` on the project site.
